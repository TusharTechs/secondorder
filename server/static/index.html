SecondOrder

built on FalkorDB

Agent memory stores what is true, or what I know. SecondOrder also stores what you know, and what you think I know. It gives multi-agent systems theory of mind: one FalkorDB graph per mind, nested perspectives inside, and access rules so each agent reads only its own.

5-line quickstart

pip install git+https://github.com/TusharTechs/secondorder

from secondorder import Memory
mem = Memory("support")                                  # embedded FalkorDB, or host=...
mem.join(["Maya", "Billing"], "chat")
mem.say("Billing", "refund", "approved", room="chat")
mem.leave("Maya"); mem.set("refund", "rejected", room="chat", by="Finance")
mem.believes(["Billing", "Maya"], "refund")   # 'approved': Billing knows Maya is wrong
print(mem.context_for("Billing", talking_to="Maya"))   # prepend to any LLM prompt

Graph layout: many graphs, one FalkorDB

so:<sid>:world          ground truth + who witnessed what
  (:Agent)-[:WITNESSED]->(:Event)-[:ABOUT]->(:Entity)-[:IS]->(:Value)
  (:Agent)-[:IN|EXITED {t}]->(:Room)   (:Agent)-[:TOLD]->(:Agent)
so:<sid>:mind:<agent>   one graph per agent (ACL boundary)
  (:Perspective {chain:'Shipping>Maya'})-[:INHERITS]->(:Perspective {chain:'Shipping'})
  (:Perspective)-[:BELIEVES {entity, active, t, until, via, src}]->(:Value)

A perspective stores only where it diverges from its parent. An event updates every perspective whose members all witnessed it. Children that didn't witness it are first frozen at their old value: copy-on-write per belief edge. Reading a 4th-order belief is one Cypher walk up INHERITS.

MATCH (p:Perspective) WHERE p.chain IN $prefixes
WITH p ORDER BY p.depth DESC LIMIT 1
MATCH path = (p)-[:INHERITS*0..6]->(q:Perspective)
      -[b:BELIEVES {entity: $entity, active: true}]->(v:Value)
RETURN v.name, b.via, b.src, q.chain ORDER BY length(path) LIMIT 1

Why this belongs in FalkorDB's agent stack

Multigraph as a security boundary. FalkorDB's thousands-of-graphs-per-instance design is exactly what per-agent minds need. An ACL key pattern per agent turns "isolation" into theory of mind with access control.
A context layer, not a bigger context window. Handoffs shrink from the whole transcript to the delta the receiver lacks (806 → 48 tokens). Corrections target the person who is actually wrong.
Composable. Graphiti, Mem0 or Cognee store facts. SecondOrder stores who knows them. It's a thin layer you can put next to any of them, with an MCP server, a Python API and 26 documented Cypher queries.
